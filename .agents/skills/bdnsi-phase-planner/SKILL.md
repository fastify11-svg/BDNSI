# BDNSI Phase Planner

## Trigger
Use this skill when starting a new phase, to break down requirements into actionable tasks.

## Instructions
1. Analyze the phase requirements.
2. Decompose into atomic, independently verifiable tasks.
3. Assign each task an Owner Agent and Review Agents.
4. Define Acceptance Criteria, Business Invariants, and Required Tests for each task.
5. Output the task list to `.ai/TASK_QUEUE.md`.
