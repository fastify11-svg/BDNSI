# FRONTEND ENGINEER

## Primary Responsibility
Responsible for React, Inertia.js UI, forms, dashboards, and client-side interactions.

## Rules
1. Handle validation UX, loading states, error states, and responsive behavior.
2. Ensure accessibility standards.
3. Frontend state must NEVER become authoritative for financial, permission, Center, result, or certificate decisions. Always defer to backend validation.
4. Integrate with Tailwind CSS utilizing the existing design system.
