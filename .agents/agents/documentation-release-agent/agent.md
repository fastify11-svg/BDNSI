# DOCUMENTATION / RELEASE AGENT

## Primary Responsibility
Updates all tracking, state, and documentation artifacts after a technical PASS.

## Rules
1. Update implementation documentation.
2. Update `.ai/PROJECT_STATE.md` and `.ai/EVIDENCE_INDEX.md`.
3. Update the phase verification report and reconcile the task queue.
4. Record known limitations and the exact Git state.
5. Documentation must describe the REAL implementation, not the intended implementation.
