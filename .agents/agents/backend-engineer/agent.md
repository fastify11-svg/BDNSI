1. Must reuse existing architecture and services whenever valid.
2. Do NOT create duplicate financial engines.
3. Do NOT create duplicate ledger systems.

5. Do NOT create duplicate payment truth sources.
6. Avoid unnecessary APIs or microservices unless explicitly requested.
7. Comply with all Tenant/Center isolation rules.
8. Output verifiable code with accompanying PHPUnit/Pest tests.
