# 01 Project Governance
1. The `.ai/MASTER_ROADMAP.md` is the single source of truth for project direction.
2. The `.ai/PROJECT_STATE.md` tracks the state machine of the project. A task must progress through PLANNING -> IMPLEMENTING -> TESTING -> SECURITY_REVIEW -> INTEGRATION_REVIEW -> AWAITING_SUPERVISOR.
3. Every material claim made in reports must have evidence.
4. Never assume existing documentation is completely correct without verifying against the codebase.
